# maxkallaway — хук + субтитр + Kallaway карточкалар

Сен (Claude Code) осы нұсқаулықты пайдаланушы берген сілтемеден оқыдың. Монтаж **пайдаланушының өз репосында**: қозғалтқыш `~/maxkallaway-kit`-ке жүктеледі, жұмыс файлдары мен дайын видео — `<репо>/maxkallaway/` ішінде.
Пайдаланушы қай тілде жазса, сол тілде жауап бер. Техникалық сөзді аз қолдан.

## 0. Орта (сессия басында бір рет)
```bash
[ -d ~/maxkallaway-kit ] && git -C ~/maxkallaway-kit pull -q || git clone -q --depth 1 https://github.com/shalabaymaksat/maxkallaway-kit ~/maxkallaway-kit
bash ~/maxkallaway-kit/setup.sh          # ffmpeg + numpy/pillow/requests/faster-whisper/gdown
```
- **Shell күйі командалар арасында сақталмайды** — әр Bash командасын `source ~/maxkallaway-kit/env.sh && …` деп баста (`$E` = engine, `$CREO_HOME` = `<репо>/maxkallaway`).
- `git clone` / `pip` / Drive желіге шыға алмаса → тоқта, айт: Claude Code environment баптауында **Network access → Full** қойып, жаңа сессия ашу керек.
- Транскрипция — жергілікті Whisper (faster-whisper, CPU), API кілт керек емес. Бірінші рет модель жүктеледі (large-v3 ~3 GB, 1–3 мин). Тілі: әдепкі қазақша; орысша видео — `export CREO_LANG=ru`.

## 1. Видеоларды алу + жоба
Google Drive **папкасы** немесе жеке видео сілтемесі («Anyone with the link» болуы керек), не репоға салынған файл (`maxkallaway/inbox/`):
```bash
source ~/maxkallaway-kit/env.sh && python3 $E/new_project.py <жоба_аты> "https://drive.google.com/drive/folders/…"
```
Жоба: `$CREO_HOME/projects/<жоба_аты>/`, `list.txt` — видео нөмірлері (01, 02… әліпби ретімен), `videos.py` + `anims.py` үлгілері көшіріледі. Жүктелмесе (0 видео, HTML файл) — сілтеме жабық: «Anyone with the link»-ті сұра.
Ары қарай әр команда: `source ~/maxkallaway-kit/env.sh && cd $CREO_HOME/projects/<жоба_аты> && export RAZBOR_WORK=$PWD/ RAZBOR_SRC=$PWD/src/ && …`

## 2. Транскрипция (әр видео N)
```bash
RAZBOR_PROMPT="<терминдер, өнім/бренд аты>" python3 -W ignore $E/stt_chunks.py N
python3 -W ignore $E/stt_turbo.py N                 # екінші нұсқа — салыстыру үшін
python3 -W ignore $E/verify_fill.py N 0.22          # ыңылдау («ыы», «эээ»)
python3 $E/seg.py a b whisper-large-v3 kk "терминдер" NN   # күмәнді жерді қайта тыңдау
```
Қазақша STT қателеседі — нұсқаларды салыстырып, мағынасына қарай қалпына келтір; күмәнді сөзге **[?]**.

## 3. Камера аралықтары
Адам камераға қараған бір сәтті эталон ал (`REF_N REF_SEC`, кадр-парақпен тап):
```bash
python3 $E/cam.py REF_N REF_SEC N …       # C = камера, c = күмәнді, . = экран/басқа
```
Кадр-парақпен көзбен раста → `anims.py`-дағы `cam`. Экран жазбасы өз дыбысымен ойнайтын жер — `videos.py`-дағы `play`.

## 4. МӘТІНДІ ПАЙДАЛАНУШЫҒА БЕКІТТІР — БЕКІТІЛМЕЙІНШЕ ФИНАЛ РЕНДЕР ЖОҚ
Видеоларды **бір-бірлеп** көрсет (бәрін бір хабарламаға үйме). Әр видеоға:
1. хуктың 3 нұсқасы (A/B/C, CAPS, тырнақшада);
2. субтитр мәтіні (нөмірленген жолдар, күмәнді жер **[?]**) + жуан кілт сөздер;
3. «сөз → карточка» жоспары;
4. қай жер камера / экран.
Бір кадрлық тест (`--test`, 5-қадам) суретін көрсет. Пайдаланушы түзетеді не «дұрыс» дейді → сосын ғана рендер.

## 5. Конфиг + тест кадр
- `videos.py`: `VIDEOS[N] = dict(CAM_HOOK немесе SCR_HOOK, hook='“…”', keys=[…], play=[(a,b)], text="""…""", cut=[(a,b)])`. Мәтін: кіші әріп, әр жол — сөйлем (карточка шекарасы), айтылғанға жақын (тайминг Whisper сөздеріне туралау арқылы); латын/2+ бас әріпті сөздер өз күйі; ерте шыққан жолға басында `@src_сек` анкер.
- `anims.py`: `ANIMS[N] = dict(cam=[(a,b)], end=…, items=[(сөз_түбірі, бөліктер, sfx), …])` — **айтылу ретімен**. Бөліктер: `'claude'`, `'yt'`, `'arrow'`, `'tiles1'/'tiles2'/'tiles3'`, `('e', '🔥')`, `('t', 'мәтін')`, `('h', 'сары маркер')`. sfx: `pop`, `pop2`, `snip`, `click`. `KEEP` — бас әрпі сақталатын сөздер.
```bash
python3 -W ignore $E/kw_render.py N --test 3 45     # → test/NN_*.jpg (Read арқылы қара)
python3 -W ignore $E/dry.py N                       # tokens == shown болуы керек
```

## 6. Рендер (фонда) + тексеру
```bash
bash $E/run.sh 1 2 3        # run_in_background: 1-өту → mkcheck (шыққан аудионы қайта тану) → 2-өту → ready/
```
Логта `!! камерадан табылмады` → сөз түбірін/ретін түзет. Әр видеоны көзбен тексер:
```bash
mkdir -p test && ffmpeg -v error -y -i out/01_*.mp4 -vf "fps=1/2,scale=216:384,tile=8x2" -frames:v 1 test/sheet01.jpg
```
+ карточка сәттерінің кадры. Дайыны: `$CREO_HOME/ready/<жоба_аты>/NN_*.mp4`.

## 7. Тапсыру
```bash
cd "$(git rev-parse --show-toplevel)" && git add maxkallaway/ && git commit -m "maxkallaway: <жоба> дайын" && git push
```
(`maxkallaway/.gitignore` аудио/уақытша файлдарды шығарады.) Пайдаланушыға: файл жолы, жүктеу — GitHub қолданбасы → репо → maxkallaway → ready → файл → Download. 100 MB-тан үлкен файл push болмайды.

## Стиль (бекітілген — өзгертпе)
- **Хук:** алғашқы ~3,8 с, қызыл `#E30613` қорап, ақ Montserrat ExtraBold CAPS. Экранмен басталса y=600 (`SCR_HOOK`), камерамен — кеудеде y≈1300 (`CAM_HOOK`).
- **Субтитр:** y=335 (бас үсті), 2–3 сөз, бір кілт сөз жуан. Ақ экран үстінде автоматты қара. `play` ішінде субтитр жоқ.
- **Карточка:** ақ, radius 34, көлеңке; ортада y=590. Мәтін ExtraBold #111 64 px; кілт сөз сары `#FFD600` маркермен. Иконалар: Claude жұлдызы `#D97757`, YouTube ▶, эмодзи 96 px, бағыт-сызық, 9:16 рилс плиткалары.
- **Уақыт:** сөз + 0,1 с → 0,16 с «поп», блюрсыз; бір карточка ≤ 2,4 с; камера аралығы біткенде жоғалады.
- **Сөз → карточка:** айтылған нәрсе көрінсін — Claude → белгі; «қиып рилс» → ✂️ → плиткалар; сан/уақыт → ⏱ + сан; CTA → 👇 **СІЛТЕМЕ**/**КНОПКА** (click).
- **Зум:** спикер тұрақты 1,0; камерада әр 3-ші сөйлем таза кесумен 1,2x (автомат). Үздіксіз зум жоқ.

## Тыйымдар
- B-roll жоқ. Көрнекі VFX (жарқыл, shake, блюр ауысу) жоқ — тек SFX.
- Анимация тек адам камераға қараған жерде; экран жазбасында карточка жоқ.
- Экрандағы сөз айтылғаннан ерте шықпайды.
- Safe zone: x 96–984, y 232–1393.
- Пайдаланушының видеосын реподан тыс жерге жіберме (бәрі сессия ішінде өңделеді).

## Гочалар
- `cut` өзгерсе ескі `out/NN.check.json`-ды өшір (`run.sh` өзі өшіреді).
- `items` айтылу ретімен: іздеу алдыңғы табылған сөзден кейін жалғасады.
- Ойнайтын видеосы көп файлда 2-өту шатасса — `videos.py`-да `pass2=False`.
- Эмодзи: Linux-та Noto (fonts/emoji/, жоқтары автоматты жүктеледі), Mac-та Apple.
