# maxkallaway — телефоннан карточка-анимациялы рилс монтажы

Камераға сөйлеген видеоларыңды Claude Code өзі монтаждайды:
- кідірістер мен ыңылдау қиылады;
- басында қызыл хук, бүкіл видеода 2–3 сөздік субтитр;
- айтылған сөзге сай ақ карточка-анимациялар (Claude белгісі, YouTube, эмодзи, сары маркер) + «поп» дыбыстары;
- дайын видеолар сенің репоңа түседі: `maxkallaway/ready/…`.

## Не керек (бір рет)
1. **Claude Pro немесе Max** жазылымы (телефондағы Claude Code тек ақылы жоспарда).
2. **GitHub аккаунты** және кез келген өз репоң (бос болса да болады). Жоқ болса: github.com → New repository → атын жаз → Private → Create.
3. Claude қолданбасы → **Code** → репоңды таңда → environment баптауы → **Network access: Full**.

API кілт керек емес: сөзді тануды (Whisper) сессияның өзі жасайды.

## Монтаж жасау
1. Видеоларды Google Drive-тағы бір папкаға сал → папкада Бөлісу → **Anyone with the link** → сілтемені көшір.
2. Claude Code-қа (өз репоңда) осыны жаз:

```
Осы нұсқаулықпен монтаж жаса: https://github.com/shalabaymaksat/maxkallaway-kit/blob/main/SKILL.md
Видеолар: <Google Drive папкасының сілтемесі>
```

3. Claude әр видео бойынша хук нұсқаларын, субтитр мәтінін және карточкалар жоспарын бір-бірлеп көрсетеді → түзет немесе «дұрыс» де.
4. Дайын видеолар репоңда: GitHub қолданбасы → репо → `maxkallaway/ready/…` → файл → Download.

## Ескерту
- Бірінші іске қосу орнатуға және Whisper моделін жүктеуге 3–5 минут алады; бір видео рендері бірнеше минут.
- Бір папкада 50-ге дейін видео.
- Репоңды **Private** ұста — ішінде өз видеоларың болады.
